# Canva Grow 营销内容合规层

本仓库汇总 Canva Grow 营销内容合规层项目的需求调研、竞品实测、PRD、测试数据、证据截图和原型实现。

## 主要内容

- `Canva Grow 营销内容合规层 PRD 2.pdf`：当前 PRD 文档
- `Canva Grow 营销内容合规层调研(1).pdf`：需求调研文档
- `Canva_Grow_实地体验记录_新账号实测.md`：Canva Grow 一手体验记录
- `竞品实测工作表_完成版.md`：竞品测试汇总
- `data.csv`、`my_test_results.csv`：测试数据与结果
- `compliance-console/`、`compliance-demo/`：两个独立的本地 Git 仓库，将分别发布，避免主仓库出现不可用的嵌套仓库引用
- `output/`、`outputs/`：生成的文档与测试产物
- `C*.png`、`G*.png`：竞品和 Canva Grow 实测证据截图
